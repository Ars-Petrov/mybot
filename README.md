# Где мои инструменты

Telegram-бот для одной семьи: общий каталог, у кого сейчас инструмент и где он лежит.
Поля владельца нет. **«Мои инструменты» — инструменты, которые сейчас у пользователя.**

## Что умеет

- Добавлять название, описание/модель, место возврата и необязательное фото.
- Показывать общий каталог и текущие инструменты пользователя с постраничной навигацией.
- Искать по названию и описанию, включая русские буквы без учёта регистра.
- Брать инструмент, в том числе у другого члена семьи, передавать и возвращать его.
- Уведомлять прежнего держателя, если другой человек сам забрал инструмент.
- Добавлять и удалять инструменты любому члену семьи; перед удалением требуется подтверждение.
- Менять текущее место отдельно от места возврата.
- Показывать последние 10 действий с временем UTC.
- Автоматически добавлять родственников по пригласительной ссылке, только в личных чатах.

Данные хранятся в SQLite и сохраняются после перезапуска. Незавершённый ввод хранится
в памяти: после перезапуска его нужно начать заново, уже добавленные инструменты сохраняются.

## Запуск (Python 3.10+)

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

1. В `.env` укажите токен своего бота от [@BotFather](https://t.me/BotFather) в `BOT_TOKEN`.
2. Запустите `python main.py`. На сервере, из папки проекта, выполните
   `python manage.py invite` (тем же пользователем, что запускает бота).
3. Откройте выведенную ссылку в Telegram и нажмите Start. Бот сам сохранит ваш ID.
4. В меню нажмите «Пригласить семью» или отправьте `/invite`, затем передайте ссылку
   родственникам. После открытия ссылки и нажатия Start они получают доступ и появляются
   среди получателей передачи. Менять `.env` и перезапускать бота для этого не нужно.

`FAMILY_IDS` теперь необязателен: существующие значения импортируются в базу при запуске.
Можно оставить его пустым и добавить всех, включая первого человека, через ссылку.
Приглашённые участники сохраняются в SQLite и входят после перезапуска без ссылки.
Обычный `/start` от незнакомого человека доступа не даёт. Ссылка многоразовая: любой,
кто её получил, может вступить в семью с полным доступом к каталогу. Любой участник
может получить приглашение и заменить его командой `/newinvite`. Прежняя ссылка
тогда перестаёт работать, а уже вступившие сохраняют доступ.

Если в бота пока никто не вступил, приглашение можно заменить на сервере командой
`python manage.py newinvite`. Отдельных ролей администратора и интерфейса исключения
участников пока нет; удаление ID из `.env` не отзывает ранее сохранённый доступ.

Запускайте одну копию бота для одного токена. Если старый прототип уже работает,
остановите его перед запуском этой версии. Бот работает через long polling; открывать
входящий порт и настраивать HTTPS не требуется. Компьютер/сервер должен быть включён
и иметь доступ к Telegram. Токен не публикуйте и не коммитьте `.env`.

## Пример

Добавьте «Перфоратор Bosch», место «Гараж, стеллаж». Нажмите «Взять себе» — он
появится в «Моих инструментах». Укажите текущее место «Багажник». При передаче Ивану
инструмент исчезнет из вашего списка и появится у Ивана. Место остаётся прежним,
пока его не уточнят. После «Вернуть» инструмент снова лежит в «Гараж, стеллаж»
и ни за кем не числится.

Передавать, возвращать и перемещать занятый инструмент может только его текущий
держатель. Любой член семьи может взять инструмент себе, даже если он числится у
другого человека. Прежнему держателю придёт уведомление с именем того, кто забрал инструмент.
Текущее место при этом сохраняется; новый держатель может уточнить его в карточке.
Взятие и уведомление записываются в одной транзакции; очередь сохраняется после перезапуска.
При сбое Telegram отправка повторяется с задержкой. Если человек заблокировал бота,
уведомление останется в очереди до возможности доставки. После успешной отправки
оно помечается доставленным; при аварии между отправкой и записью статуса возможен повтор.
Любой член семьи может удалить даже занятый инструмент. Он исчезает из общего и
личных списков, но запись и история остаются в базе для восстановления. Кнопки старой
карточки после удаления не работают. Восстановление через интерфейс пока не реализовано.
Старые кнопки не перезаписывают новые изменения: откройте карточку заново.
Фото хранится как Telegram file_id, а не как локальный файл.

## Резервная копия

Для удалённого Linux-сервера и копий на Windows подготовлены службы, таймер,
скрипт загрузки и задание Планировщика: **[развёртывание и бэкапы](deploy/README.md)**.

По умолчанию снимок создаётся ежедневно в 03:00 по Москве; сервер хранит 30 снимков.
ПК скачивает доступные копии ежедневно в 20:00 по своему местному времени и при входе
в Windows, проверяет SHA-256 и хранит 90 снимков. Время можно изменить в настройках.
Расписания начнут работать только после установки служб и задания на ваших устройствах.

Ручной согласованный снимок без остановки бота:

```bash
python backup.py --database data/tools.sqlite3 --destination backups --keep 30
```

В снимок входят каталог, история, участники и их доступ, действующее приглашение,
отметки удаления и очередь уведомлений. После восстановления действует ссылка из
выбранного снимка; замените её через `/newinvite`, если нужно отозвать старую.
Токен и `.env` не включаются. Фото представлены Telegram file_id для того же бота.
База не заменяет отдельный архив самих фотографий.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют SQLite, одновременную выдачу, права, сохранение данных, а также
диалоги и кнопки через настоящий диспетчер aiogram с подменой Telegram API.
Для проверки в живом Telegram требуется запущенный бот с вашим токеном.

В этой версии нет редактирования названия/фото, напоминаний
и подтверждения передачи получателем. Передача фиксируется сразу по выбору отправителя.
